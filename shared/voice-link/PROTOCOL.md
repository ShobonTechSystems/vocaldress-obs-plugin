# VocalDress の声の受け渡し（約束の版 1）

VocalDress のアプリ（書き手）から OBS のプラグイン（読み手）へ、声を渡す形です。実装は同じフォルダの `kv_voice_link.h`（形と読み書き）と `kv_voice_link_shm.h`（共有メモリと時計）で、どちらも MIT です（[LICENSE](LICENSE)）。この2つは libobs にも、アプリのほかの部品にも依存しません。

## 共有メモリ

- 名前：Windows は `Local\VocalDressVoiceLink.v1`、それ以外は POSIX の `/VocalDressVoiceLink.v1`
- 大きさ：4 MiB で固定。書き手が作り、読み手は読むだけで開く
- 時計：Windows は `QueryPerformanceCounter`、それ以外は `CLOCK_MONOTONIC` を ns にしたもの。OBS の `os_gettime_ns` と同じ時計

## 並び

先頭（40 バイト、リトルエンディアン）：

| 位置 | 型 | 中身 |
| --- | --- | --- |
| 0 | uint32 | magic `0x4C56564B`（"KVVL"） |
| 4 | uint32 | 約束の版（1） |
| 8 | uint32 | サンプルレート（8000〜384000） |
| 12 | uint32 | ch の数（1 か 2） |
| 16 | uint32 | 1ブロックのフレーム数（16〜8192、既定 480＝10 ms） |
| 20 | uint32 | リングのブロック数（4〜4096、既定 50） |
| 24 | atomic uint32 | epoch：書き手の起動ごとに変わる番号。0 は準備中 |
| 28 | uint32 | 予約（0） |
| 32 | atomic uint64 | 書き終えたブロックの数（増え続ける） |

続けて、ブロックごとの「書いた時刻」（uint64 × ブロック数）、サンプル（float32、ch 交互、ブロック数 × フレーム数 × ch）が並びます。ブロック n はリングの n mod ブロック数 番目に入ります。

## 書き手

1. epoch を 0 にしてから先頭を書き、最後に 0 以外の epoch を release で置く
2. ブロックごとに、サンプルと書いた時刻を書いてから、書き終えた数を release で 1 進める

書き手は1つだけです。読み手を待ちません。

## 読み手

- epoch・magic・版・形式を確かめ、合わなければ読まない（送り手を待つ）
- 書き終えた数を acquire で読み、まだ読んでいないブロックを写す。写したあとに epoch と書き終えた数をもう一度確かめ、写している間に一周されていたら捨てる
- 一周されたとき（読むのが遅れた）と、epoch が変わったとき（書き手の起動し直し）は、最新から少し手前（既定 2 ブロック）へ合わせ直す
- OBS に渡す時刻は、最初のブロックの「書いた時刻」に結び付け、以後はサンプルの位置から続けて作る。プラグインはこれに 20 ms を足して渡す（アプリは OBS 側のズレの計算にこの値を使う）

約束を変えるときは、版と共有メモリの名前の末尾（`.v1`）を一緒に上げます。
